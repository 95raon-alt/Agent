# 📖 나만의 IT/AI 용어 사전

| 용어 | 영문/원어 | 설명 |
| :--- | :--- | :--- |
| **UI** | User Interface | 컴퓨터와 사람을 소통할 수 있게 이어주는 가장 큰 개념의 **'사용자 다리(매개체)'**입니다. |
| **GUI** | Graphical User Interface | UI의 한 종류로, 화면의 **'그림(아이콘, 버튼)'**을 마우스로 클릭하거나 터치해 명령하는 직관적인 방식입니다. |
| **CLI** | Command Line Interface | UI의 한 종류로, 화면에 **'글자(텍스트)'**를 직접 쳐서 명령하는 방식입니다. 파이프라인(작업지시서)을 읽고 묵묵히 실행한 뒤 브리프보고서를 생성하는 데 탁월합니다. |
| **파이프라인** | Pipeline | 컴퓨터가 순서대로 처리해야 할 일들을 텍스트로 쭉 적어둔 **'작업지시서'**입니다. |
| **브리프보고서** | Brief Report | 컴퓨터가 지시받은 일을 끝낸 후, 사람이 결과를 한눈에 파악할 수 있도록 핵심만 요약해 보여주는 **'요약보고서'**입니다. |
| **에이전트** | Agent | 단순 대화를 넘어, 목표를 주면 스스로 계획을 세우고 다양한 도구를 사용해 실제 작업을 끝까지 완수하는 **'자율적인 대리인(비서)'**입니다. |
| **서브에이전트** | Sub Agent | 복잡한 일을 총괄하는 메인 AI 아래에서, 특정 업무만 빠르고 정확하게 전문으로 처리하는 **'전문 실무자'** 역할의 AI입니다. |
| **md 파일** | Markdown | 사람과 AI 모두 읽고 이해하기 쉽도록 작성된 문서 형식으로, AI에게 업무 방향과 목적을 알려주는 **'전체적인 가이드라인'** 역할을 합니다. |
| **skill 파일** | (규칙서) | 서브에이전트가 특정 작업을 수행할 때 지켜야 할 '구체적인 규칙과 활용할 수 있는 기술'이 적힌 문서입니다. "이런 상황에서는 이 도구를 써서 이렇게 행동해라"라고 정해둔 엄격한 **'행동 규칙서'이자 '도구함'** 역할을 합니다. |
| **제미나이** | Gemini | Google이 개발한 대형 언어 모델(LLM)로, 생각하고 코드를 이해하며 추론하는 **'지능(두뇌/엔진)'** 역할을 합니다. |
| **안티그래비티** | Antigravity | 제미나이(두뇌)를 탑재하고 파일 편집, 터미널 명령 실행, 브라우저 제어 등 실제 도구를 다뤄 작업을 완수하는 **'손발을 갖춘 완성형 AI 에이전트'**입니다. |
| **아이덴티티** | Identity | 사람, 브랜드, AI 등이 가진 **'고유한 정체성(본질과 캐릭터)'**입니다. 예를 들어 "이 브랜드의 핵심은 차분함이다"처럼 남들과 구별되는 고유한 색깔과 기준을 의미합니다. |
| **와이어프레임** | Wireframe | 색상이나 화려한 디자인을 배제하고, 버튼과 글자의 위치 등 화면의 전체적인 구조와 배치를 단순한 선과 상자로 표현한 **'화면의 건축 설계도(뼈대)'**입니다. |
| **스토리보드** | Storyboard | 와이어프레임(화면 뼈대) 위에 사용자의 이동 경로, 버튼 클릭 시 일어나는 동작, 예외 상황 등 화면의 모든 작동 원리를 상세히 적어둔 **'화면의 종합 연출 대본(작동 설명서)'**입니다. |
