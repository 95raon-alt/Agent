# 홈페이지 레퍼런스 리서치 (Research Skill)

이 Skill은 **A:FIT (에이핏)** 프로젝트의 건강기능식품, 웰니스 및 UI/UX 벤치마킹 홈페이지 레퍼런스 자료를 탐색, 수집, 누적 및 중복 통합 관리한다.

## 1. 기본 리서치 자료 자동 인식
- `리서치/` 폴더 내 파일명에 `[리서치_결과]`가 포함된 모든 파일(예: `AFIT_건강기능식품_레퍼런스_20선_샘플보고서_[리서치_결과].txt`, `AFIT_건강기능식품_레퍼런스_200선_마스터보고서_[리서치_결과].txt`)을 기본 자료로 탐색하고 병합한다.
- 해당 파일이 존재하지 않는 경우 임의의 파일을 읽지 않고 사용자에게 즉시 안내한다.
- 원본 리서치 파일은 절대로 수정하거나 덮어쓰지 않는다.

## 2. 추가 리서치 자료 증분 입력 ("리서치 자료 추가 입력")
- 사용자가 "리서치 자료 추가 입력" 명령을 내리면 이후 제공되는 파일(`.txt`, `.md`, `.pdf`), URL, 텍스트를 추가 자료로 누적 수집한다.
- 기존 자료를 덮어쓰지 않고 기본 자료와 추가 자료의 출처를 구분하여 표기한다.

## 3. 중복 홈페이지 통합 및 출처 보존
- 동일한 브랜드/URL의 홈페이지가 발견되면 1개 항목으로 통합한다.
- 통합 시 발견된 모든 원본 파일명 및 출처 기록을 보존한다.
