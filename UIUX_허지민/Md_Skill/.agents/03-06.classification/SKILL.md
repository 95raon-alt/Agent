# 홈페이지 레퍼런스 분류 (Classification Skill)

이 Skill은 반드시 **리서치 레퍼런스 데이터 확인 → 분류 기준 매핑안 작성 → 사용자 승인**의 단계로 실행한다. 매핑안을 스스로 승인하지 않으며, 승인 후 다음 단계(분석)로 전달한다.

## 🛡️ 승인 게이트

1. `리서치/` 폴더 또는 리서치 파싱 결과로 확보된 레퍼런스 목록이 존재하는지 확인한다.
2. 4단계(분류 기준)에 대한 입력/기본 기준이 확보되었는지 확인한다.
3. 대상 자료가 없으면 무엇이 필요한지 사용자에게 알리고 중단한다.

사용자 요청: `$ARGUMENTS`

## 1단계: 분류 기준 매핑안 작성

1. 리서치 파싱 완료된 홈페이지 데이터를 읽는다.
2. 확정된 분류 기준(예: 산업/타깃/디자인 톤앤매너/주요 UI 패턴 등)을 적용한다.
3. 각 홈페이지가 어느 카테고리에 부합하는지 임시 그룹화를 진행하여 분류 매핑안을 작성한다.
4. 분류 요약과 미분류(누락) 점검 결과를 보고하고 승인을 요청한 뒤 대기한다.

매핑안 승인 전에는 다음 단계(상세 분석 및 결과 파일 작성)를 수행하지 않는다.

## 2단계: 분류 확정 및 전달

사용자가 명시적으로 승인한 경우:
1. 분류 매핑 결과를 확정(`approved`) 처리한다.
2. 확정된 분류 카테고리 구조를 `analysis` (상세 분석) 단계로 전달한다.
3. 원본 및 분류 기록을 보존하고 분류 요약표를 제공한다.
