# 홈페이지 레퍼런스 통합 마스터 워크플로우 (Integrated Master Skill)

이 Skill은 **A:FIT (에이핏)** 프로젝트의 홈페이지 레퍼런스 **1단계: 리서치(자료수집) → 2단계: 분류(카테고리 매핑 및 승인) → 3단계: 분석(7대 UI/UX 상세 분석 및 100개 단위 UTF-8 TXT 보고서 출력/검증)**의 전체 과정을 순서대로 통괄하여 실행한다.

---

## 🛡️ 1단계: 리서치 (Research & Data Gate)

1. `리서치/` 폴더 내 파일명에 `[리서치_결과]`가 포함된 모든 기본 리서치 자료를 탐색하고 식별한다.
2. 사용자가 "리서치 자료 추가 입력" 명령을 통해 누적 수집한 추가 파일/URL/텍스트가 있는지 확인한다.
3. 분석할 대상 리서치 파일이 하나도 없으면 필요한 자료를 안내하고 즉시 작업을 중단한다.
4. 대상 파일(기본 자료 + 추가 자료)을 읽고 브랜드 및 웹사이트 URL을 파싱한다.
5. 중복된 홈페이지가 발견될 경우 1개 항목으로 통합하되, 발견된 **모든 출처 정보를 기록에 보존**한다.
6. 원본 리서치 파일은 절대로 수정하거나 덮어쓰지 않는다.

---

## 🏷️ 2단계: 분류 (Classification Gate)

1. 리서치 완료된 홈페이지 레퍼런스 목록을 확정된 분류 기준(카테고리/유형/타깃 등)에 맞춰 임시 그룹화 매핑안을 작성한다.
2. 분류 매핑안 작성 후 분류 요약 및 누락 점검 결과를 보고하고 사용자 승인을 요청한 뒤 대기한다. (스스로 승인하지 않음)
3. 사용자가 명시적으로 승인한 경우(또는 승인 완료 상태일 때)에만 3단계 분석 절차로 진행한다.

---

## 🔍 3단계: 분석 및 보고서 출력 (Analysis & Output Validation)

1. 분류 승인된 레퍼런스 데이터를 바탕으로 개별 홈페이지 및 카테고리별 **7대 분석 항목**을 적용하여 상세 분석을 진행한다:
   - 1. 기본 정보 (서비스명, URL, 업종, 타깃, 출처)
   - 2. 디자인 스타일 (분위기, 색상, 글꼴, 이미지, 여백, 애니메이션)
   - 3. 화면 구성과 레이아웃 (첫화면, 헤더/메뉴, 콘텐츠배치, 섹션순서, 푸터, 모바일)
   - 4. 메뉴와 사용자 흐름 (메뉴구조, 인지정보, CTA버튼, 이동동선, 혼동지점)
   - 5. 문구와 콘텐츠 (핵심카피, 설명방식, 신뢰내용, 후기/수치, 행동유도문구)
   - 6. 주요 기능 (검색, 회원가입/로그인, 상담, 구매, 필터/정렬, 특징기능)
   - 7. 평가 (잘된점, 아쉬운점, 참고할점, 지양점, 적용아이디어)
2. 전체 자료 비교 분석 항목 중 '반복 화면 구성' 명칭은 **`공통 레이아웃 패턴 (자주 사용되는 화면 레이아웃)`**으로 적용한다.
3. 분석 완료 결과는 `output/` 폴더에 **UTF-8 인코딩 `.txt` 파일**로 생성한다.
4. **100개 단위 분할**: 1개 텍스트 파일당 최대 100개 홈페이지로 제한한다 (`01_홈페이지별_분석_001-100.txt` 형식).
5. **무단절 보존**: 단일 홈페이지의 7대 분석 항목 전체는 절대로 2개 파일로 쪼개지 않으며, 경계에 걸치는 경우 통째로 다음 파일 첫 머리로 이관한다.
6. **최종 검증**:
   - 파일 존재 여부 및 크기(>0 byte) 확인
   - UTF-8 인코딩 `.txt` 포맷 확인
   - 파일당 100개 이하 제한 및 무단절 보존 지켜졌는지 확인
   - 7대 분석 항목 완비 여부 확인
7. 검증 통과 후 생성 파일 목록, 총 분석 수, 검증 결과를 요약 보고한다.
