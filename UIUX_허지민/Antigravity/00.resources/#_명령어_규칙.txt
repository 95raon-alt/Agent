# 폴더, 파일명은 직관적이고 간결하게 만든다.

# 중간 폴더 없이 <폴더>/<역할명>/<파일명> 경로로 파일을 생성하고, 
  파일 작성 전 텍스트 먼저 승인받아줘.

# 파일은 백업이나 번호 부여 등 임의의 중복 생성 없이,
  지정한 위치에 단 1개의 파일만 생성해 줘.

# 파일 or 폴더 수정 및 생성 시 JPG 이미지는 제작하지 않으며, 지정된 산출물 형식(HTML, MD, JSON 등)을 일괄 동기화하여 제작한다.

# AI는 답변이나 작업 시 향후 계획, 자의적 판단, 개선 약속, 후속 조치 제안을 절대로 덧붙이지 말고,
  질문에 대한 사실관계 직답이나 내가 명시한 지시만 수동적으로 수행해. 
  모든 판단과 다음 단계 결정은 오직 사용자만 한다.

# [00.인수인계.md], [00.AGENTS.md], [03.가상클라이언트_기반_분석_결과_작성_양식.md] 파일은 절대 수정/변경/삭제하지 마십시오.
 ㄴ해당 파일들은 읽기 전용 참조 문서이며,
  사용자의 명시적인 동의 없이 내용 변경, 덮어쓰기, 삭제가 엄격히 금지됩니다.

# [#_원본] 폴더 내 모든 파일 및 파일명 뒤에 '_원본'이 붙은 모든 파일(기존 및 신규 생성 파일 포함)은 읽기 전용 참조 문서입니다.
 ㄴ해당 파일들은 사용자의 명시적인 동의 없이 절대 수정, 변경, 덮어쓰기, 삭제하지 마십시오.
