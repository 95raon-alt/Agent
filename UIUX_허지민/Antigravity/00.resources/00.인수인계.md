## ⚙️ 4. 확정된 핵심 운영 & 데이터 규칙 (Core Rules & Constraints)

### 1) 기본 자료 자동 인식 규칙
- 파일명에 **`[리서치 결과]`**가 들어간 모든 파일(예: `AFIT_건강기능식품_레퍼런스_20선_샘플보고서 [리서치 결과].txt`)을 자동으로 탐색하여 기본 리서치 자료로 병합합니다.
- 해당 조건에 맞는 파일이 없을 경우 임의의 파일을 읽지 않고 사용자에게 알립니다.

### 2) 추가 자료 증분 입력 규칙 ("리서치 자료 추가 입력")
- 사용자가 **"리서치 자료 추가 입력"**이라고 명령하면 이후 제공되는 파일(`.txt`, `.md`, `.pdf`), URL, 직접 입력 텍스트를 추가 자료로 인식합니다.
- 기존 자료를 덮어쓰지 않고 누적 저장하며, 기본 자료와 추가 자료의 출처를 명확히 구별하여 표기합니다.
- 중복 홈페이지 발견 시 1개 항목으로 통합하되, 발견된 **모든 출처 정보를 기록에 보존**합니다.

### 3) 결과물 출력 및 100개 단위 무단절 분할 규칙
- 모든 분석 결과 파일은 **UTF-8 인코딩 `.txt` 파일**로 생성합니다.
- **1개 텍스트 파일 당 최대 100개 홈페이지 제한** (100개 초과 시 `01_홈페이지별_분석_001-100.txt`, `01_홈페이지별_분석_101-200.txt` 형식으로 생성).
- **무단절 보존**: 한 홈페이지의 분석 내용은 절대로 두 파일로 쪼개어 나누지 않습니다. (경계에 걸칠 경우 통째로 다음 파일로 이관)

### 4) 분석 서식 및 용어 반영사항
- **홈페이지별 7대 분석 항목**: 기본 정보, 디자인 스타일, 화면 구성과 레이아웃, 메뉴와 사용자 흐름, 문구와 콘텐츠, 주요 기능, 평가
- **전체 자료 비교 분석 항목**: '반복 화면 구성'이라는 명칭은 사용자 오해 방지를 위해 **`공통 레이아웃 패턴 (자주 사용되는 화면 레이아웃)`**으로 변경 적용 완료.
