## 3. 정보 구조 (Information Architecture)

- **주제:** 식사+영양제 10초 컷, 커피 한 잔 값의 초개인화 이중제형 A:FIT 구독 경험
- **부주제:** 2030 시간/식비 공감, 앱 스마트 진단, 식비 절감 가성비 차트, 원핸드 10초 섭취, 타깃 공감 리뷰
- **메뉴:** 브랜드 스토리, 맞춤 진단, 가성비 혜택, 구독 신청
- **콘텐츠:** 헤드라인 카피, 3줄 요약표, 진단 모크업, 식비 비교 저울 UI, 10초 컷 GIF, 페르소나 리뷰 카드, FAQ
- **정보 유형:** 
  - **사실 (Fact):** 한 끼 3~4천 원대 가격, 10초 섭취 시간, 페르소나 리뷰, 구독 혜택
  - **개념 (Concept):** 초개인화 이중제형 건강식, 극단적 시간/식비 가성비
  - **절차 (Procedure):** 앱 연동 컨디션 진단 3단계, 정기구독 결제 동선
  - **과정 (Process):** 앱 상태 입력 ➔ 캡슐 자동 매칭 ➔ 10초 섭취 ➔ 컨디션 케어

## 4. [메뉴, 콘텐츠, 기능] 상세 분석 결과

### 1) [메뉴 (Menu & Navigation)] 분석 결과

#### (1) 글로벌 내비게이션 (GNB) 구조 (Depth 2단계 이내)
2030 직장인의 정보 피로도를 최소화하도록 최단 4대 메뉴 구조로 직관화되었습니다.
- **`브랜드 스토리`**: 2030 시간/식비 부족 공감 및 A:FIT 올인원 철학
- **`맞춤 진단`**: 10초 앱 연동 컨디션 퀴즈 및 캡슐 큐레이션
- **`가성비 혜택`**: 편의점 대비 식비 절감 데이터 차트 & 저울 UI
- **`구독 신청`**: 1초 간편 결제 모달 레이어 연결

#### (2) 리서치 사이트 벤치마킹 메뉴 패턴
- **Ritual & Vitable 벤치마킹**: 텍스트를 나열하는 빽빽한 풀다운 메뉴를 배제하고, 상단 GNB 호버 시 이모지 라디오 칩(회식, 밤샘, 붓기)이 직관적으로 노출되도록 설계
- **AG1 벤치마킹**: 최상단 스크롤 위치와 관계없이 하단 고정(Sticky Bar) CTA가 상시 추종하여 탐색 중 언제든 구독 창 진입 가능

#### (1) 브랜드 메시지 & 카피라이팅 콘텐츠
- **메인 카피**: *"식사부터 영양제까지 10초 컷, 커피 한 잔 값으로 완성하는 바른 내일"*

   - 3교대 간호사 최교대(29세): "나이트 근무 때 화장실 갈 시간도 없는데 생명줄이 되어줍니다."

### 3) [기능 (Feature & Interaction)] 분석 결과

1. **상황별 이모지 칩 필터 UI (Vitable, HUM Nutrition 벤치마킹)**:
   - 밤샘/회식/붓기/야식/피로 등 5대 고민 이모지 칩 클릭 시 해당 상황에 맞는 캡슐 조합이 실시간 3D 모크업으로 변경되는 인터랙션
2. **식비 절감 데이터 저울 UI 차트 (AG1, Heights 벤치마킹)**:
   - 슬라이더를 움직여 현재 주간 편의점/배달 지출액을 입력하면 A:FIT 구독 시 절약되는 금액이 저울 기울기 애니메이션으로 직관적 시각화
3. **10초 원핸드 섭취 스크롤 3D/GIF 모션 (Seed, Heights 벤치마킹)**:
   - 스크롤을 내릴 때 화면 고정(Pinning) 상태에서 보틀과 뚜껑 캡슐이 3D 분해·결합되는 마이크로 애니메이션 구현
4. **하단 고정(Sticky Bar) 간편 결제 CTA (AG1, Vitable 벤치마킹)**:
   - 모바일 한 손 조작 영역(Thumb-Zone)에 맞춰 하단 고정 바가 유지되며, 클릭 시 1초 카카오/토스 간편 결제 레이어 팝업 연동
