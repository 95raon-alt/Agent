## 3. 화면별 구성 영역, UI 요소 및 인터랙션 명세

### 3.1 [PAGE-01] 메인 랜딩페이지
- **진입 조건**: 웹 브라우저 URL 접속 또는 검색 광고 링크 클릭
- **종료 조건**: 구독 결제 버튼 클릭(PAGE-05 이동) 또는 AI 진단 모달 열기(PAGE-03 이동)
- **주요 UI 영역 및 컴포넌트**:
  - `Header`: A:FIT Balance 로고, GNB (스토리, AI 진단, 임상 성분, 구독 혜택), 장바구니 Icon
  - `Hero Section`: "복잡한 영양제는 내려놓으세요, 하루 15초로 완성되는 3040 바이오 밸런스" 카피, 앰플+캡슐 미니멀 웰니스 오브제 비주얼
  - `Problem & 3-Line Summary`: 3040 뇌 피로/면역 저하 공감 카피, `[임상 검증 - AI 맞춤 - 15초 섭취]` 3줄 요약 카드
  - `AI Curation`: 4대 웰니스 고민 칩 (피로/수면/면역/항산화), AI 스마트폰 연동 맞춤 캡슐 추천 모크업 UI
  - `Clinical Donut Chart`: 특허 성분 함량 도넛 차트 & 세브란스 임상 데이터 그래프 (마우스 호버 시 상세 수치 인터랙션)
  - `GIF Motion`: 원터치 앰플 뚜껑을 눌러 마시는 하루 15초 섭취 스크롤 애니메이션/GIF
  - `Reviews`: 3040 전문직(금융가, 법조인, 워킹맘) 실명 후기 횡스크롤 슬라이더
  - `Sticky CTA Bar`: 화면 하단 스크롤 추종 구독 결제 바 ("내 라이프스타일 분석받고 15초 프리미엄 웰니스 시작하기")
- **반응형 대응**:
  - PC (1200px+): 12컬럼 그리드, 도넛 차트와 AI 진단 모크업 좌우 병렬 배치
  - Mobile (~767px): 1컬럼 수직 스태킹, 횡스크롤 슬라이더 touch-swipe 활성화

### 3.2 [PAGE-03] AI 진단 모달
- **15초 라이프스타일 퀴즈**: 1단계(현재 피로 고민), 2단계(수면/면역 패턴), 3단계(필요 성분) 칩 선택
- **유효성 검사**: 각 단계별 최소 1개 이상 칩 미선택 시 "다음" 버튼 비활성화 (Disabled State)

### 3.3 [PAGE-05] 구독 결제 창
- **배송지 폼 입력 규칙**:
  - 성함/연락처/배송지 주소 필수 입력. 미입력 시 `PAGE-07` 오류 모달 또는 인라인 Red Text 표시
- **1초 간편 결제**: 카카오페이 / 토스페이 / 신용카드 원터치 라디오 선택

## 5. 반응형 기준 및 접근성 표준
- **반응형 브레이크포인트**: Desktop (1200px+), Tablet (768px ~ 1199px), Mobile (~767px)
- **접근성 요구사항**:
  - 이미지 대체 텍스트 (`alt="15초 원터치 앰플 섭취 이미지"`) 명시
  - 버튼 키보드 접근성 (Tab 키 포커스 Outline 표시)
  - 명도 대비 ratio 4.5:1 이상 준수 (세이지 그린 #4A6B5D vs 크림 베이지 #F9F7F1)

## 6. 가정 사항 (Assumptions)
- `가정 1`: 비회원 구독 시 결제 단계에서 1회성 휴대폰 본인인증으로 가입이 간편 자동 완료된다.
- `가정 2`: 결제 PG사는 카카오페이, 토스페이, 국내 전 신용카드를 지원한다.
