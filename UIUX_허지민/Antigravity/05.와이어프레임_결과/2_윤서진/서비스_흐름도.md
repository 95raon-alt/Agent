# 🔄 A:FIT Balance (윤서진 디렉터) 서비스 흐름도 (Service Flowchart)

## 1. 서비스 흐름 개요
A:FIT Balance 웹사이트의 핵심 사용자 여정(User Journey)은 **[탐색(Hero/카피) ➔ 진단(AI 퀴즈) ➔ 검증(임상 도넛 차트/가치 비교표) ➔ 결정(프리미엄 구독 플랜) ➔ 결제(1초 간편결제)]**의 5단계 연속 프로세스로 설계되었습니다.

## 2. 사용자 유형 및 시작 조건
- **신규 3040 전문직/워킹맘**: 만성 피로 및 영양제 중복 오남용 고민을 가진 비회원 ➔ 메인페이지(PAGE-01) 진입
- **재방문 프리미엄 구독자**: 마이페이지 로그인 회원 ➔ AI 맞춤 캡슐 변경 또는 배송 주기 관리 진입

## 3. 핵심 정상 흐름 (Happy Path)
1. **[메인 진입]**: PAGE-01(메인 랜딩) 접속 ➔ Hero 3040 피로 공감 카피 및 3줄 요약 확인
2. **[AI 스마트 진단]**: 4대 고민 칩(피로/수면/면역/항산화) 클릭 ➔ PAGE-03(AI 진단 모달) 15초 퀴즈 완료
3. **[임상/가치 검증]**: 캡슐 매칭 결과 확인 ➔ PAGE-04(임상 차트/가치 비교표)에서 특허 성분 및 절감 가치 확인
4. **[구독 옵션 선택]**: 구독 주기(2주/4주/8주) 선택 ➔ '내 라이프스타일 분석받고 15초 프리미엄 웰니스 시작하기' 클릭
5. **[결제 진행]**: PAGE-05(구독 결제 창) 이동 ➔ 배송지 입력 ➔ 카카오페이/토스 1초 간편 결제
6. **[완료 확인]**: PAGE-06(구독 완료) 이동 ➔ 첫 배송 타임라인 확인

## 4. 분기, 오류, 이탈 및 재진입 흐름
- **[분기 1: 비회원 vs 회원]**: 결제 단계(PAGE-05)에서 비회원 1초 휴대폰 본인인증으로 즉시 자동 가입
- **[오류 1: 결제 실패]**: 잔액 부족 또는 카드 오류 시 PAGE-07(오류 모달) 노출 ➔ 이전 결제수단 선택 화면 유지
- **[오류 2: 필수 입력 누락]**: 배송지 미입력 시 인라인 Red 에러 텍스트 표시 및 포커스 이동
- **[이탈 방어]**: 이탈 포커스 발생 시 "프리미엄 웰니스 스타터 키트 1만원 할인 쿠폰" 팝업 모달 노출 ➔ 재진입 유도

## 5. 단계별 서비스 프로세스 명세 표

| 단계 | 사용자 행동 | 시스템 처리 (System Action) | 표시 화면 | 다음 진입 조건 |
| :---: | :--- | :--- | :--- | :--- |
| **01** | 메인페이지 접속 | 모바일/PC 레이아웃 최적화, 스크롤 프로그레스 바 로드 | PAGE-01 메인 | 탐색 스크롤 진행 |
| **02** | 4대 웰니스 고민 칩 클릭 | 선택 칩 Highlight, AI 맞춤 캡슐 추천 모크업 실시간 전환 | PAGE-01 / PAGE-03 | AI 진단 시작 클릭 |
| **03** | 15초 라이프스타일 퀴즈 완료 | AI 바이오 알고리즘 연산 ➔ 맞춤 캡슐 팩 조합 도출 | PAGE-03 진단 모달 | 결과 확정 및 구독하기 클릭 |
| **04** | 임상 성분 도넛 차트 확인 | 특허 성분 함량 및 낱개 대비 절감 가치 연산 노출 | PAGE-04 가치 비교 | 구독 플랜 선택 |
| **05** | 구독 결제 버튼 클릭 | 로그인 여부 검증 ➔ 결제 레이어 모달 호출 | PAGE-05 결제 창 | 배송지 입력 및 결제 승인 |
| **06** | 간편 결제 승인 | PG사 결제 승인 ➔ DB 구독 등록 ➔ 알림톡 전송 | PAGE-06 완료 창 | 마이페이지 이동 또는 종료 |

## 6. Mermaid Flowchart Diagram Syntax

```mermaid
flowchart TD
    Start([시작: 메인 접속]) --> Hero[PAGE-01: Hero 탐색]
    Hero --> Quiz{AI 바이오 진단 실행?}
    
    Quiz -- 예 --> Modal[PAGE-03: AI 진단 모달]
    Quiz -- 아니오 --> Value[PAGE-04: 임상 성분 & 가치 비교]
    
    Modal --> Recommendation[맞춤 캡슐 팩 도출]
    Recommendation --> Value
    
    Value --> PlanSelect[프리미엄 구독 플랜 선택]
    PlanSelect --> Checkout[PAGE-05: 구독 결제 창]
    
    Checkout --> PaySuccess{결제 승인 성공?}
    PaySuccess -- 성공 --> Success[PAGE-06: 구독 완료]
    PaySuccess -- 실패 --> Error[PAGE-07: 오류/예외 모달]
    
    Error --> Checkout
    Success --> End([종료: 배송 안내])
```
