## 3. 화면별 구성 영역, UI 요소 및 인터랙션 명세

### 3.1 [PAGE-01] 메인 랜딩페이지
- **진입 조건**: 웹 브라우저 URL 접속 또는 SNS 뷰티 광고 링크 클릭
- **종료 조건**: 구독 결제 버튼 클릭(PAGE-05 이동) 또는 AI 큐레이션 모달 열기(PAGE-03 이동)
- **주요 UI 영역 및 컴포넌트**:
  - `Header`: A:FIT Glow 로고, GNB (스토리, AI 큐레이션, 바이오 성분, 구독 혜택), 장바구니 Icon
  - `Hero Section`: "겉만 바르지 마세요! 10초 만에 속건조 채우는 2040 바이오 이중제형 앰플" 카피, 앰플+캡슐 글로우 파스텔 비주얼
  - `Problem & 3-Line Summary`: 겉 피부 케어 한계 공감 카피, `[속건조 해소 - 개인 맞춤 - 10초 바이오 앰플]` 3줄 요약 카드
  - `AI Skin Curation`: 4대 피부 고민 칩 (속건조/미백/탄력/트러블), AI 스킨 연동 맞춤 바이오 앰플 추천 모크업 UI
  - `Absorption Donut Chart`: 초저분자 콜라겐 & 글루타치온 흡수율 도넛 차트 (마우스 호버 시 실시간 성분 흡수 연산)
  - `10s GIF Motion`: 마시는 순간 속건조가 채워지는 10초 원샷 이중제형 바이오 앰플 애니메이션/GIF
  - `Reviews`: 피부과 원장, 뷰티 에디터, 장기 구독자 실명 후기 횡스크롤 슬라이더
  - `Sticky CTA Bar`: 화면 하단 스크롤 추종 구독 결제 바 ("속건조 없이 10초 만에 끝내는 내 피부 맞춤 글로우 구독하기")
- **반응형 대응**:
  - PC Web (1920px FHD, Max-Width 1200px~1440px Container): 12컬럼 그리드, 도넛 차트와 큐레이션 모크업 좌우 병렬 배치
  - Mobile (~767px): 1컬럼 수직 스태킹, 횡스크롤 슬라이더 touch-swipe 활성화

### 3.2 [PAGE-03] AI 피부 큐레이션 모달
- **3단계 피부 퀴즈**: 1단계(피부 고민), 2단계(클렌징/생활 습관), 3단계(필요 바이오 성분) 칩 선택
- **유효성 검사**: 각 단계별 최소 1개 이상 칩 미선택 시 "다음" 버튼 비활성화 (Disabled State)

### 3.3 [PAGE-05] 구독 결제 창
- **배송지 폼 입력 규칙**:
  - 성함/연락처/배송지 주소 필수 입력. 미입력 시 `PAGE-07` 오류 모달 또는 인라인 Red Text 표시
- **1초 간편 결제**: 카카오페이 / 토스페이 / 신용카드 원터치 라디오 선택
