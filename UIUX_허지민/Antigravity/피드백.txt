현재 페이지에는 A:FIT이 시작된 문제, 브랜드 철학, 핵심 가치, 4대 인증과 5단계 제작 공정, 대표 제품 3종, 라이프스타일 맞춤 진단, 비용 계산기, 원핸드 섭취 방식, 15개 전체 상품, 후기, FAQ와 정기구독 신청까지 들어가 있어 브랜드를 이해한 뒤 제품을 탐색하고 신청하는 기본 흐름은 잘 만들어졌어 특히 상품 수를 문구로만 적어 둔 것이 아니라 7개 라이프스타일 카테고리에 총 15개 상품을 실제 카드로 구성한 점은 유지하면 돼

- 메인 홈, 브랜드 소개와 15종 컬렉션을 연결한 GNB

[수정]
우선 현재 페이지는 브랜드를 설명하는 정보가 충분하지만 고객이 보는 메인페이지와 내부 브랜드 가이드의 역할이 섞여 있어 `A + FIT` 네이밍 공식과 여섯 개 컬러의 HEX 코드, 각 색상의 사용 규칙은 브랜드 분석 문서에서는 좋은 내용이지만 고객용 메인페이지에서는 흐름을 길게 만들 수 있어 네이밍의 의미는 짧은 브랜드 문장으로 남기고 상세 컬러 팔레트와 코드 복사 기능은 브랜드 가이드 파일로 분리하는 것이 좋아

히어로에서는 나이트 오버타임 팩, 하루 3,800원, 월 79,800원, 하루 1병과 1:1 각인 정보가 동시에 강조되고 있어 첫 화면에서 가장 먼저 기억해야 할 내용이 분산될 수 있어 `불규칙한 하루를 한 병의 맞춤 루틴으로 정리한다`처럼 브랜드 핵심 메시지 1개와 대표 제품 1개를 가장 크게 보여주고 가격, 각인과 구독 정보는 두 번째 우선순위로 정리해 줘
대표 제품 3종을 좌우 교차로 강조한 부분은 잘했지만 왜 이 세 제품이 A:FIT의 대표인지 선택 기준이 부족해 각 제품을 아래처럼 서로 다른 대표 상황과 연결하면 좋아
- 프로틴 머슬 빌더: 운동 전후의 단백질과 활력 관리
- 나이트 시프트 슬립: 불규칙한 교대 근무와 휴식 루틴
- 블루라이트 아이 쉴드: 장시간 화면을 보는 직장인과 개발자의 집중 루틴

각 대표 제품에는 대상만 적는 것보다 사용자가 겪는 문제, A:FIT의 해결 방식, 섭취 시간, 상단 정제와 하단 액상의 역할 및 전체 15종 중 어떤 라인에 속하는지를 같은 순서로 보여줘 대표 제품을 본 다음 전체 상품 영역에서 같은 제품을 쉽게 다시 찾을 수 있도록 대표 배지나 연결 CTA도 추가하면 좋고, 현재 맞춤 진단은 7개 탭 중 하나를 누르면 바로 처방 결과가 나오는 구조라서 `1:1 맞춤`, `정밀 배합`, `AI 진단`이라는 표현에 비해 실제 입력 과정이 단순해 보여 이 기능을 유지하려면 생활 패턴, 가장 불편한 시간대, 섭취 목적과 선호 제형처럼 최소한의 질문 과정을 추가하거나, 현재 구조를 유지할 경우에는 `라이프스타일별 추천`으로 이름을 조정해 기능의 실제 수준과 표현을 맞춰 줘
15개 상품은 실제로 구성되어 있지만 대부분 같은 카드 밀도와 동일한 월 가격으로 반복돼 성분명을 제외하면 상품 차이를 빠르게 비교하기 어려워 상품 카드의 정보 순서를 아래처럼 통일해 줘
- 라이프스타일 카테고리
- 상품명
- 해결하려는 생활 문제 한 줄
- 상단 정제와 하단 액상의 핵심 차이
- 추천 섭취 시점
- 용량 또는 구독 구성
- 가격 또는 가격 확인 상태
- 상세보기와 구독 CTA

필터도 7개 라이프스타일 분류만 제공하고 있어서 사용자가 자신의 상황을 모르면 선택하기 어려울 수 있어 생활 유형 외에 `아침·업무 중·운동 전후·야간·취침 전` 같은 섭취 시점이나 `활력·집중·회복·수면·이너뷰티·소화` 같은 목적 기준을 추가해 줘 필터 결과가 없을 때의 안내, 전체보기로 돌아가는 초기화, 로딩과 오류 상태도 함께 설계해야 해
현재 시안에서 가장 먼저 수정해야 하는 부분은 수치와 인증 표현이야 `92.4% 다이렉트 체내 흡수`, 식약처 기능성 인정, GMP 승인 번호, 프랑스 EVE VEGAN, KCL 180일 생분해, 누적 구독자 12,000명, 평점 4.95, 재구독 만족도 98.4%, 대한민국 No.1과 전문가·실사용자 선택 같은 문구가 실제 근거 없이 확정된 사실처럼 보이고 있어 실제 자료가 있다면 출처와 연결하고, AI가 만든 프로젝트 설정이라면 `가상 데이터`, `표현 예시`, `검증 필요`로 표시하거나 일반적인 브랜드 목표와 제작 콘셉트로 바꿔 줘 건강기능식품의 흡수, 수면, 눈 건강, 항산화와 체내 작용을 설명하는 문장도 실제 효능처럼 단정하지 말고 근거와 허용 표현을 확인해야 해

후기 영역도 현재 `VERIFIED REVIEWS`, 실제 구독자 수와 구체적인 효능 체감 문구를 사용하고 있어 가상 클라이언트를 실제 고객 후기처럼 보이게 만들 수 있어 가상 클라이언트는 제품과 기능을 설계한 근거로만 사용하고, 후기는 `사용자 시나리오`, `가상 인터뷰 기반 예상 사용 장면`처럼 역할을 분명히 구분해 줘 실제 후기 영역을 유지하려면 출처가 확인된 데이터만 사용해야 해, 비용 계산기는 인터랙션 자체는 좋지만 절약 금액과 시간의 계산 근거가 화면에 보이지 않아 결과를 그대로 신뢰하기 어려워 식사 1회 기준 비용, A:FIT 1병 가격, 준비 시간과 계산식을 함께 보여주고 사용자가 기준값을 직접 바꿀 수 있도록 해 줘 가격과 구독 할인도 확정된 사업 정보가 아니라면 가안임을 표시해야 해

디자인 관점에서는 브랜드 철학, 핵심 가치, 네이밍, 컬러, 인증과 공정에서 작은 카드와 설명이 연속되어 페이지 중간의 시각적 밀도가 높아 보여 브랜드 시작은 실제 생활 장면을 담은 큰 이미지와 짧은 문장, 이중제형 기술은 제품 단면도, 제작 과정은 가로 타임라인, 대표 제품은 현재의 좌우 교차 구성, 전체 15종은 규칙적인 카드 그리드처럼 섹션의 역할에 맞춰 강약을 나눠 줘 지금 CSS 오브제와 이모지로 표시한 제품 영역도 최종 포트폴리오에서는 실제 제품 이미지가 들어갈 비율, 촬영 방향, 재질 표현, 사용 장면과 대체 텍스트가 있는 이미지 영역으로 발전 시키는게 좋아

신청 모달에는 학생 이름과 실제 전화번호처럼 보이는 값이 기본으로 들어가 있으니 빈 입력값이나 `홍길동`, `010-0000-0000` 같은 명확한 예시로 교체해 줘 제출 버튼을 누른 뒤 알림창만 띄우는 것보다 입력 오류, 전송 중, 신청 완료와 재시도 상태를 모달 안에서 보여주는 것이 좋아

접근성도 추가로 확인해야 해 상품 상세 모달에는 대화상자 역할과 제목 연결을 제공하고, 모든 닫기 버튼에는 `닫기`라는 접근 가능한 이름을 넣어 줘 모달을 열면 첫 입력이나 제목으로 포커스가 이동하고, Tab 키가 모달 안에서 순환하며, ESC로 닫힌 뒤 원래 누른 버튼으로 포커스가 돌아오도록 설계해야 해 필터 버튼의 선택 상태, FAQ의 펼침 상태와 폼 레이블도 화면 표시뿐 아니라 코드에서 확인할 수 있게 연결해 줘

### [1차 피드백] 15종 상품 확장 및 브랜드 스토리 분산 배치 (기존)
--------------------------------------------------------------------------------
[메인페이지_와이어프레임_시안1.html]을 삭제하거나 처음부터 다시 만들 필요는 없어. 
현재 시안의 맞춤 배합 진단, 가성비 계산기, 10초 섭취 메커니즘, FAQ와 신청 모달 같은 
기능·설계상 장점은 그대로 유지하면 되고.

현재 메인페이지는 7개 섹션과 7대 라이프스타일 라인업 중심이라 최소 15개의 상품을 
보여주는 기준에는 부족해, 먼저 전체 상품을 최소 15개로 확정하고 각 상품에 대상 
사용 상황, 핵심 차이와 연결할 브랜드 근거를 기반으로 사용 목적이나 구성에서 
구분되는 상품이면 좋아.

기존 7명의 클라이언트와 설계 내용은 삭제하지 말고, 기존 설계 중심 클라이언트 
요구사항에 A:FIT의 브랜드와 디자인 완성도를 중요하게 보는 요구사항을 추가하고, 
회사의 시작 배경과 철학, 개인 맞춤 웰니스 원칙, 기술과 제작 과정, 검증된 성과를 
사용자가 이해할 수 있는 브랜드 콘텐츠로 보강하면 돼.

제품 15개를 한 구역에 카드로 전부 나열하지 말고 중요한 제품을 관련된 이야기와 
함께 여러 섹션에서 각각 강조해주고, 
- Hero에서는 A:FIT의 대표 제품 1개를 브랜드의 핵심 가치와 함께 크게 보여주고, 
- 회사 철학 영역에서는 대표 제품이 어떤 문제를 해결하는지 연결해줘. 
- 기술·제작 과정에서는 제형이나 사용 방식의 차이를 보여주는 제품을 강조하고, 
- 라이프스타일 영역에서는 기존 7대 라인업을 사용 상황별로 소개하면 돼.
- 중간에는 대표 제품 2~3개를 큰 이미지, 화면 분할과 좌우 교차 배치로 각각 강조할 수 있는 방법도 있고,
- 모든 핵심 제품을 충분히 설명한 다음 페이지 후반에 최소 15개 전체 상품을 한눈에 확인하고 카테고리 페이지로 이동할 수 있는 전체 제품 모음 영역을 제공하면 좋아.

정리하면:
`기존 시안과 클라이언트 유지 → 브랜드·디자인 요구사항 추가 → 최소 15개 고유 상품 추가 → 회사 철학·기술·제작 과정 콘텐츠 보강 → 대표 상품을 여러 섹션에서 서로 다른 레이아웃으로 강조 → 전체 상품 모음 제공 → 기존 기능과 새 브랜드 콘텐츠 최종 병합` 
순서로 진행하면 돼!

#### 1. 고객용 메인페이지 vs 내부 브랜드 가이드 분리
- `A + FIT` 네이밍 공식은 1줄의 직관적인 브랜드 핵심 문장으로 축약.
- 6개 브랜드 컬러 HEX 코드, 색상 규칙, 복사 버튼 등 내부 가이드성 요소는 브랜드 가이드 문서로 분리하여 메인페이지 흐름을 간결화.

#### 2. 히어로(Hero) 섹션 정보 우선순위 재정렬
- 가격(3,800원/79,800원), 1일1병, 1:1각인 등이 동시 과다 노출되는 시각적 분산 해결.
- **최우선(Primary)**: `불규칙한 하루를 한 병의 맞춤 루틴으로 정리한다` (핵심 메시지 1개 + 대표 제품 1개 전면 강조).
- **차순위(Secondary)**: 가격, 각인, 구독 혜택 정보는 서브 정보로 정돈.

#### 3. 대표 제품 3종 선정 기준 명확화 및 전체 15종 연결
- **선정 배경 부여**:
  - `프로틴 머슬 빌더`: 운동 전후 단백질 & 에너지 활력 루틴
  - `나이트 시프트 슬립`: 불규칙 3교대 근무 및 야간 심신 이완/휴식 루틴
  - `블루라이트 아이 쉴드`: 장시간 모니터 업무 직장인 & 개발자의 시각 피로/집중 루틴
- **정보 표기 순서 일원화**: [생활 문제 → A:FIT 해결 방식 → 섭취 시점 → 상단 정제 & 하단 액상 역할 → 15종 중 소속 라인]
- **네비게이션 연결**: 대표 제품 전용 배지(`[대표 제품]`) 및 전체 15종 섹션의 해당 카드로 스크롤 이동하는 CTA 추가.

#### 4. 맞춤 진단 현실화 또는 명칭 조정
- **방안**: 7개 탭 즉시 결과 표출의 단순함을 개선하기 위해:
  - (A) 2~3단계의 핵심 문항(생활 패턴, 취약 시간대, 섭취 목적, 선호 제형)을 통한 진단 스텝 추가, 또는
  - (B) 명칭을 `라이프스타일별 맞춤 큐레이션 추천`으로 명확히 표현하여 기능 수준과 일치화.

#### 5. 15종 상품 카드 정보 계층 표준화
- 동일 가격/밀도 반복을 탈피하고, 성분 외 차이점을 한눈에 비교할 수 있도록 카드 내 정보 순서 통일:
  1. 라이프스타일 카테고리 태그
  2. 상품명
  3. 해결하려는 생활 문제 (한 줄 요약)
  4. 상단 정제 & 하단 액상의 핵심 성분 차이
  5. 추천 섭취 시점
  6. 용량 및 구독 구성
  7. 가격 (가안 표기)
  8. 상세보기 & 구독 신청 CTA

#### 6. 다차원 필터 시스템 & 상태(State) 설계
- **기존 7대 라이프스타일** 외 다차원 필터 탭 추가:

  - **섭취 목적별**: `전체 | 활력 | 집중 | 회복 | 수면 | 이너뷰티 | 소화`
- **시스템 상태 UI 추가**: 필터 결과 0건 시 빈 상태(Empty State) 안내 + "전체보기로 초기화" 버튼, 로딩/오류 상태 설계.

#### 7. 미검증 수치·인증·효능의 투명한 정직성 확보 (포트폴리오 신뢰도)
- 근거 없는 단정적 수치(`92.4% 흡수`, `식약처 인증 번호`, `EVE VEGAN`, `12,000명`, `재구독 98.4%`, `대한민국 No.1` 등) 정비:
  - `* 가상 프로젝트 콘셉트 데이터입니다`, `* 포트폴리오용 표현 예시입니다` 등의 각주 명시 또는 브랜드 목표치 문장으로 전환.
  - 건기식 허용 표현 준수 (질병 예방/치료 효능으로 오인되지 않도록 건강 증진/활력 서포트 문구로 정제).

#### 8. 가상 클라이언트 후기 & 비용 계산기 근거 노출
- **후기 영역**: 실제 고객 후기로 오인되지 않도록 `[가상 페르소나 인터뷰 기반 예상 시나리오]`로 명확히 명시.
- **비용 계산기**: 절약액 산출 근거(외식/배달 1회 비용 vs A:FIT 1병 가격, 제조/준비 시간 절약식)를 화면에 직접 표시하고 사용자가 슬라이더/인풋으로 기준값을 직접 조정 가능하도록 개선.

#### 9. 섹션별 시각적 강약 조절 & 실제 제품 이미지 가이드
- 작은 카드 형태의 연속으로 인한 페이지 중간의 시각적 피로도 해소:
  - **브랜드 시작**: 실제 생활 장면 대형 비주얼 + 굵고 짧은 카피
  - **이중제형 기술**: 제품 단면 구조 다이어그램 (Infographic)
  - **제작 공정**: 가로 타임라인 스텝 뷰
  - **대표 3종**: 좌우 교차 대형 스포트라이트
  - **15종 전체**: 규칙적인 그리드 아카이브
- CSS/이모지 플레이스홀더를 포트폴리오용 실제 제품 렌더링 규격(비율, 앵글, 재질감, alt 텍스트)으로 고도화.

#### 10. 개인정보 예시 정제 & 웹 접근성(A11y) 완비
- **신청 모달 폼**: 실제 학생 이름/전화번호 제거 → `홍길동`, `010-0000-0000` 가상 플레이스홀더 적용.
- **폼 상태 처리**: 제출 시 `alert()` 대신 모달 내부 인라인 유효성 검사, 로딩(Spinner), 신청 완료 화면, 재시도 안내 UI 구현.
- **키보드 & 스크린리더 접근성**:
  - 모달 `role="dialog"`, `aria-modal="true"`, `aria-labelledby` 연결.
  - 모든 닫기 버튼에 `aria-label="닫기"` 명시.
  - 모달 오픈 시 첫 포커스 진입, Tab 키 순환(Focus Trap), ESC 키 닫기, 닫힌 후 원래 버튼으로 포커스가 돌아오도록 설계.
  - 필터 버튼 `aria-pressed`, FAQ 아코디언 `aria-expanded`, 모든 input에 `<label for="...">` 완벽 결속.
