### [브랜드소개 1차 피드백] 브랜드 스토리 압축, 시그니처 듀얼 팩 단면 도해, 인증 카드 반응형/가로넘침 및 접근성 개선 (이전)

브랜드소개 시안1은 A:FIT이 왜 시작됐는지, 어떤 문제를 해결하려는지, 어떤 원칙과 제작 과정을 갖고 있는지 한 페이지 안에서 이해할 수 있게 구성한 점이 좋아 메인페이지에 있던 상세 색상 가이드를 브랜드 소개 페이지로 분리한 방향도 맞게 적용됐어 컴퓨터 화면에서는 브랜드 이야기, 기존 영양제와 A:FIT의 비교, 인증과 제작 과정, 브랜드 색상으로 이어지는 정보 순서가 안정적이고 390픽셀 화면에서도 대부분의 영역이 한 줄 구조로 자연스럽게 바뀌고 있어 지금 구조를 다시 만들 필요는 없어

브랜드가 어떤 문제에서 시작됐는지, 어떤 원리로 해결하는지, 사용자의 일상이 어떻게 달라지는지를 긴 설명보다 큰 이미지와 짧은 문장으로 전달하는 것이야 또 브랜드 이해, 대표 제품 이해, 사용 장면, 신뢰 근거와 다음 페이지 이동의 역할을 구분하고 전체 상품은 브랜드 소개 안에 반복해서 나열하지 않고 상품 카테고리 페이지에서 탐색하게 만드는 기준이야

A:FIT에는 이 기준을 아래처럼 적용하면 돼
- 브랜드가 시작된 문제는 여러 영양제, 불규칙한 식사와 복잡한 섭취 습관으로 압축
- 해결 원리는 상단 정제와 하단 액상을 한 병에 결합한 이중제형 구조로 집중
- 사용자의 변화는 여러 약통과 물을 챙기는 하루에서 한 병 루틴으로 바뀌는 장면으로 표현
- 대표 제품은 `A:FIT 시그니처 듀얼 팩` 한 개를 브랜드 철학과 기술을 보여주는 사례로 우선 강조
- 전체 15종은 현재처럼 별도 서브카테고리 페이지에서 비교하고 브랜드 소개에는 이동 버튼만 제공
- 구매 신청보다 브랜드 이야기 탐색을 먼저 보여주고 구독과 컬렉션 이동은 페이지 후반부에서 한 번만 강조
- 페이지에 맞는 레퍼런스를 따로 선정하고 각 사례에서 참고할 목적을 한 줄로 먼저 정리


[유지]

- 바쁜 일상, 여러 영양제와 위장 부담을 브랜드가 해결하려는 문제로 연결한 내용

## 📝 2. [브랜드소개] 피드백 핵심 요약 & 7대 실행 로드맵 (Brand Intro Action Plan)

### 🛡️ [1] 100% 유지할 핵심 자산 (Keep)

2. **문제 정의 맥락**: 바쁜 일상, 수많은 약통 관리 번거로움, 위장 부담 해결 스토리

5. **문제 대조 구조**: 기존 영양 습관(약통+물) vs A:FIT 하루 1병 이중제형 좌우 비교
6. **신뢰 근거 분리**: 4대 공인 인증 기준 씰과 5단계 무균 질소 제조 공정 분리 구성

10. **신청 플로우 분리**: 3-State (입력 폼 ➔ 처리 중 스피너 ➔ 완료 화면)

### 🔧 [2] 중점 수정 및 고도화 과제 8대 영역 (Refine & Modify)

#### 1. 정보 구역 역할 재정의 및 시각적 강약 배분 (Visual Rhythm)
- **문제점**: 첫 화면부터 긴 설명 카드, 3개 원칙 카드, 비교 카드, 인증 카드, 색상 카드가 연속되어 '브랜드 스토리'보다 '설명서/보고서' 느낌이 강함.
- **개선 방안**:
  - **[브랜드 이해]**: 핵심 문장 + 시작 계기 + 1줄 네이밍 + 3대 원칙으로 간결화.
  - **[제품 이해]**: `A:FIT 시그니처 듀얼 팩` 상단 정제 · 하단 액상 단면 도해 및 섭취 방식.
  - **[사용 장면]**: 여러 약통 챙기는 과거 하루 vs 한 병 루틴으로 바뀐 일상 비교.
  - **[신뢰 근거]**: 원료 선택 기준 + 5단계 제작 공정 + 가상 데이터 명시.
  - **[브랜드 가이드]**: 6대 컬러, 각 색의 역할과 실제 UI 적용 예시.
  - **[다음 행동]**: 페이지 최하단에서 '15종 컬렉션 보기' 또는 '맞춤 진단 시작' 우선순위 CTA 제공.

#### 2. 첫 화면 CTA 우선순위 전환 & 구매 문구 중복 제거
- **Hero CTA 변경**: 
  - (기존) 첫 버튼이 `15종 맞춤 컬렉션 보기`로 상품 구매가 앞섬.
  - (변경) 1순위 버튼을 **`A:FIT이 시작된 이유 보기`** 또는 **`한 병 루틴의 원리 알아보기`**로 전환하여 스토리 탐색 유도.
- **구매 유도 위치 단일화**: 15종 컬렉션 및 정기구독 유도는 브랜드 스토리와 제작 공정을 충분히 확인한 **페이지 후반부에서 1회만 집중 강조**.
- **중복 점검**: GNB 및 상단 메뉴와 페이지 내부의 반복적인 구매 버튼 노출 최소화.

#### 3. 대표 제품 `A:FIT 시그니처 듀얼 팩` 1종 단면 도해 신설
- **문제점**: 브랜드 소개 페이지에 실제 제품을 보여주는 영역이 없어 철학과 실물 제품의 연결고리가 약함.
- **개선 방안**:
  - 3대 원칙 직후에 **`A:FIT 시그니처 듀얼 팩` 1종**을 단독 섹션으로 배치.
  - **대형 제품 이미지 + 상단 정제/하단 액상 분리 단면 도해(Infographic Layout)** 적용.
  - 이 제품이 왜 올인원, 개인 맞춤, 이중제형의 집약체인지 핵심 원리 설명 (15종 전체 비교는 서브카테고리 페이지로 연결).

#### 4. 레퍼런스 목적화 및 1줄 적용 목적 명시
- 무분별한 링크 나열을 배제하고 **사용성 / 디자인 / 무드** 3개 축으로 1~2개 엄선.
- 각 레퍼런스별 적용 목적을 1줄로 명시:
  - *예: "사용성: 모바일에서 긴 브랜드 스토리 탐색 시 현재 스크롤 위치 인디케이터 참고"*
  - *예: "디자인: 상단 캡슐과 하단 액상의 물리적 결합 단면 도해 표현 기법 참고"*
  - *예: "무드: 바쁜 직장인의 현실적 아침과 한 병 루틴의 대조적 톤앤매너 참고"*

#### 5. 모바일 390px 반응형 가로 넘침(542px 버그) 완전 해결
- **문제점**: 390px 화면에서 4개 인증 카드가 1줄(4열)로 고정되어 카드 폭이 100~138px로 찌그러지고 높이가 441px까지 늘어나며 문서 전체 폭이 542px로 넘침.
- **개선 방안**:
  - `768px 이하 (태블릿)`: 인증 카드 그리드를 **2열(2 Columns)**로 전환.
  - `480px 이하 (모바일)`: 인증 카드 그리드를 **1열(Single Column)**로 전환.
  - 인증 제목, 인증 번호, 상세 설명이 카드 내부에서 자동 줄바꿈(`word-break: keep-all; overflow-wrap: break-word;`)되도록 처리.
  - 390px 뷰포트에서 가로 스크롤 완전 박멸 (`overflow-x: hidden; width: 100%; box-sizing: border-box;`).

#### 6. 개인정보 예시 정제 & 폼 유효성 검사 (Form Validation)
- **푸터 정보**: 대표자명 `홍길동(가상)`, 사업자등록번호 및 통신판매번호 `예시 번호` 표기 및 `* 본 사이트는 UI/UX 포트폴리오용 가상 프로젝트입니다` 명시.
- **신청 모달 기본값**: 기존 `value`에 박힌 학생 개인정보/실제 번호 완전 제거 ➔ `placeholder` 안내 문구로 전환.
- **유효성 검증**: 성명 2자 이상, 휴대폰 번호 정규식(`010-XXXX-XXXX`), 주소 필수 입력 검증 및 인라인 에러 피드백 문구 제공.

#### 7. 웹 접근성(A11y) 및 모달 인터랙션 고도화
- **모달 키보드 제어**:
  - CS 고객센터 모달 열림 시 ➔ 닫기 버튼 또는 헤딩으로 포커스 이동.
  - 정기구독 신청 모달 열림 시 ➔ '이름 입력 칸(`input#name`)'으로 첫 포커스 자동 진입.
  - `Tab / Shift+Tab` 키가 모달 내부에서만 순환하는 **포커스 트랩(Focus Trap)** 적용.
  - `ESC` 키 입력 시 모달 닫기 및 모달을 호출했던 **원래 버튼으로 포커스 복귀(Focus Restore)**.
  - 모달 활성화 시 배경 본문 스크롤 차단(`body { overflow: hidden; }`) 및 배경 요소 접근 차단(`aria-hidden="true"`).
- **오류 및 재시도 상태 UI**: 통신 장애/입력 오류 시 모달 내 '신청 실패 안내' 및 '다시 시도하기' 화면 구축.
- **색상 카드 및 아이콘 버튼화**:
  - 클릭 가능한 `div` 컬러 카드를 키보드로 접근 가능한 `<button>` 태그로 전환.
  - `aria-label="딥 포레스트 그린 #183D33 색상 코드 복사"` 명확한 스크린리더 레이블 부여.
  - GNB 검색 돋보기 아이콘도 `aria-label="통합 검색 열기"` 명칭을 가진 버튼으로 전환.

#### 8. 디자인 관점 이미지 영역(Visual Assets) 기획
- 긴 텍스트 중심을 탈피하고 와이어프레임 및 최종 포트폴리오에 필요한 **6대 핵심 이미지 영역** 계획:
  1. **Hero 일상 씬**: 바쁜 직장인의 아침과 한 병 루틴 대조 (`16:9` 또는 `4:5` 래쇼).
  2. **사용 전후 대조 씬**: 5~6개 약통 챙기는 하루 vs 한 병으로 가벼워진 포켓 루틴.
  3. **시그니처 단면 씬**: 상단 맞춤 정제 + 하단 액상 결합 단면 그래픽.
  4. **5단계 제조 공정 씬**: 원료 검수 ➔ 타정 ➔ 포뮬라 ➔ 질소 충진 ➔ 맞춤 라벨 출고 현장.
  5. **에코 리필 씬**: 180일 생분해 식물성 용기 및 수거 에코백 근접 클로즈업.
  6. **대체 텍스트(alt)**: 모든 이미지에 시각 장애인 및 구조 이해를 돕는 명확한 해설 문구 첨부.
