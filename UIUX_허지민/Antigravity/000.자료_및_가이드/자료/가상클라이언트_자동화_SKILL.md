# 🚀 가상 클라이언트 4단계 자동 실행 파이프라인 (Virtual Client Automation)

본 스킬은 새로운 가상 클라이언트 디렉터가 지정되면 **가상 클라이언트 브리프 ➔ 분석 결과서 ➔ 데스크톱/PC 중심 와이어프레임 및 설계 9종(사이트맵.md/mmd/svg, 서비스_흐름도.md/mmd/svg, 화면_목록.json, 화면_설계서.md, 와이어프레임.html) ➔ 메인페이지 표 스토리보드**의 4단계를 순차적으로 실행하고, 모든 산출물 생성 시 `00.프로젝트_안내서.md`에 자동 반영하도록 규정합니다.

---

## 💻 [필수 지침 1] 데스크톱/PC 중심 대화형 반응형 웹 규격 (Desktop-Centric Web Requirement)

1. **기본 타깃 매체 고정**: 가상 클라이언트 4단계 산출물 작성 시 적용 매체는 모바일 앱 단독이 아닌 **'데스크톱/PC 중심 대화형 반응형 웹 (Desktop-Centric Responsive Web)'**을 기본 플랫폼으로 고정 적용한다.
2. **데스크톱 레이아웃 컴포넌트 필수 반영**:
   - **GNB**: 상단 풀 브라우저 폭(Full Width) 네비게이션 헤더 및 드롭다운 메뉴
   - **Body Grid**: 1200px ~ 1440px 이상 대화면 3열/4열 카드 그리드, 좌우 Split Hero 뷰
   - **시각화 & 대시보드**: 데스크톱 모니터에 최적화된 넓은 저울 데이터 시각화 차트 및 B2B 대시보드 UI
   - **와이어프레임.html**: 100% 데스크톱 대화면 반응형 풀스크린 프로토타입 구현

## 🎯 [필수 지침 2] 클라이언트별 방문/구매 목적 다변화 원칙 (Client Use-Case Diversification)

1. **브랜드 기본 정체성 및 가치 구분**: 
   - **'2030 시간/식비 절감 영양 해결 + 개인 건강상태 1:1 맞춤 진단 분석 + 진단 기반 알고리즘 자동 생성 개별 메시지 각인 패키징'** 솔루션은 **[본인 직접 섭취/구매 유즈케이스]**일 때 전용으로 적용하는 핵심 서비스 모델로 규정한다.
   - 선물하기, B2B 기업 구매, 전문가 제휴 등 본인 구매 외의 유즈케이스에는 각 클라이언트의 고유한 방문/구매 목적에 최적화된 독자적인 셀링 포인트와 UI 모델을 부여한다.
2. **알고리즘 자동 생성 커스텀 메시지 메커니즘 (본인 구매 시)**:
   - 본인 구매 유즈케이스의 개별 라벨 메시지는 1:1 맞춤 진단 분석 결과에 따라 알고리즘이 개인별 컨디션 맞춤 문구를 자동 도출하여 제품에 각인한다. (예: *"어제 밤샘 야근한 OOO님을 위한 붓기 타파 팩"*)
3. **클라이언트별 방문/구매 목적(Use Case) 및 UI 반영 예시**:
   - **본인 직접 섭취 목적**: 식비/시간 절감 데이터 저울 UI + 1:1 맞춤 진단 퀴즈 모크업 + 진단 결과 기반 자동 생성 라벨 3D 프리뷰 UI
   - **선물하기 목적**: 선물 수령인 전용 웰니스 카드 UI + 선물 축하 메시지 라벨 작성 폼 + 럭셔리 기프트 패키징 3D 뷰어
   - **B2B / 기업 복지 구매 목적**: 임직원 복지 수량별 할인율 데이터표 + 기업 응원 문구 일괄 라벨링 UI + 견적서 다운로드 UI
   - **전문가 큐레이션/제휴 목적**: 세브란스/해외 임상 검증 차트 + 전문가 처방 알고리즘 연동 + 프로 처방 라벨 UI
4. **UI/UX 다각도 검증 적용**: 각 클라이언트의 고유한 방문 목적에 맞춰 메인페이지의 **핵심 UI 컴포넌트, 카피라이팅, 라벨 인터랙션, 내비게이션 동선, CTA**를 차별화 배치함으로써 다양한 사용자 UI를 다각도로 확인하고 설계하도록 규정한다.

## 📌 실행 4단계 프로세스

### [1단계] 가상 클라이언트 브리프 생성 (`Antigravity/02.가상_클라이언트/<이름>.md`)
- **템플릿 양식**: `가상클라이언트_기반_분석_결과_작성_양식.md` 9대 규격 준수
- **포함 항목**:
  1. 가상 클라이언트 기본 정보 설정 (클라이언트별 고유 방문/구매 목적 명시)
  2. 클라이언트 요구사항 표 (중요도, 관련 자료, 필요 기능)
  3. 정보 구조 분해 표 (주제, 부주제, 메뉴, 콘텐츠)
  4. 분류 및 노출 순서
  5. 계층 구조 트리 (메뉴 폭 5~9개, 깊이 5단계 이내)
  6. 레이블링 검토
  7. 내비게이션 연결 구조
  8. 화면 영역 구성 (헤더, 내비게이션, 바디, 어사이드, 푸터)
  9. 최종 작성 검토

### [2단계] 가상 클라이언트 분석 결과서 생성 (`Antigravity/03.가상클라이언트_분석_결과/<이름>_결과.md`)
- **분석 범위**: 타깃 브랜드 컨셉에 적합한 8개 레퍼런스 사이트 매핑
- **포함 항목**:
  1. 클라이언트 정보 및 요구사항 분석
  2. 요구사항 기반 8개 레퍼런스 사이트 매핑 표
  3. 3대 분야 심층 분석 (UX 구조, 브랜딩/비주얼, 인터랙션)
  4. 정보 구조 및 내비게이션 매핑
  5. 핵심 화면 및 콘텐츠 영역 설계
  6. 최종 작성 검토

### [3단계] 와이어프레임 및 설계 9종 생성 (`Antigravity/00.output/05.와이어프레임_결과/<이름>/`)
- **생성 파일 9종 (종류 및 내용)**:
  1. `사이트맵.md` (계층 구조 및 페이지 목적 표)
  2. `사이트맵.mmd` (Mermaid flowchart 구조도)
  3. `사이트맵.svg` (Mermaid CLI 변환 벡터 이미지 파일)
  4. `서비스_흐름도.md` (사용자 여정 및 처리 단계 표)
  5. `서비스_흐름도.mmd` (Mermaid flowchart 흐름도)
  6. `서비스_흐름도.svg` (Mermaid CLI 변환 벡터 이미지 파일)
  7. `화면_목록.json` (화면 ID, 이름, 목적, 액션 유효 JSON 데이터)
  8. `화면_설계서.md` (화면 ID 규칙, 반응형 및 예외 사양 명세)
  9. `와이어프레임.html` (브라우저 단독 실행 대화형 인터랙티브 웹앱)

### [4단계] 메인페이지 표 형식 스토리보드 생성 (`Antigravity/00.output/04.스토리보드_결과/01.md/<이름>_스토리보드.md`)
- **형식**: 메인페이지 구성 섹션별(PAGE-01-SEC01 ~ SEC10) **화면 1개/섹션 1개당 10대 항목 표준 표 작성**
- **표준 10대 항목**:
  1. 화면/섹션 ID
  2. 화면명/영역명
  3. 화면/섹션 목적
  4. 진입/종료 조건
  5. 와이어프레임 레이아웃
  6. 표시 데이터 & 카피
  7. 사용자 액션
  8. 시스템 연동 & 화면 전환
  9. 예외 & 반응형 사양
  10. 가정 사항
