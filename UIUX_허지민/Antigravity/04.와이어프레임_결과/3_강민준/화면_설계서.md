## 3. 화면별 구성 영역, UI 요소 및 인터랙션 명세

### 3.1 [PAGE-01] 메인 랜딩페이지
- **진입 조건**: 웹 브라우저 URL 접속 또는 SNS 스포츠 광고 링크 클릭
- **종료 조건**: 구독 결제 버튼 클릭(PAGE-05 이동) 또는 AI 큐레이션 모달 열기(PAGE-03 이동)
- **주요 UI 영역 및 컴포넌트**:
  - `Header`: A:FIT Pro 로고, GNB (스토리, AI 큐레이션, 퍼포먼스 성분, 구독 혜택), 장바구니 Icon
  - `Hero Section`: "설탕 0g, 한 손으로 부스팅하라! 운동 10초 전 마시는 2040 피트니스 올인원" 카피, 앰플+캡슐 네온 스포티 비주얼
  - `Problem & 3-Line Summary`: 스포츠 음료 당류 과다 공감 카피, `[당류 0g - 종목 맞춤 - 10초 부스팅]` 3줄 요약 카드
  - `AI Curation`: 4대 운동 종목 칩 (러닝/웨이트/골프/등산), AI 스포츠 연동 맞춤 부스터 추천 모크업 UI
  - `Zero-Sugar Donut Chart`: 당류 0g 및 아미노산/전해질 비율 도넛 차트 (마우스 호버 시 실시간 성분 비율 인터랙션 연산)
  - `GIF Motion`: 운동 직전 원터치 앰플 뚜껑을 눌러 마시는 10초 원핸드 부스팅 애니메이션/GIF
  - `Reviews`: 스포츠 크루(러닝크루, 크로스피터, 트레이너) 실명 후기 횡스크롤 슬라이더
  - `Sticky CTA Bar`: 화면 하단 스크롤 추종 구독 결제 바 ("당류 0g 내 운동 종목 맞춤 부스팅 구독 시작하기")
- **반응형 대응**:
  - PC Web (1920px FHD, Max-Width 1200px~1440px Container): 12컬럼 그리드, 도넛 차트와 큐레이션 모크업 좌우 병렬 배치
  - Mobile (~767px): 1컬럼 수직 스태킹, 횡스크롤 슬라이더 touch-swipe 활성화

### 3.2 [PAGE-03] AI 종목 큐레이션 모달
- **3단계 운동 퀴즈**: 1단계(운동 종목), 2단계(주간 운동 횟수/강도), 3단계(필요 케어 성분) 칩 선택
- **유효성 검사**: 각 단계별 최소 1개 이상 칩 미선택 시 "다음" 버튼 비활성화 (Disabled State)

### 3.3 [PAGE-05] 구독 결제 창
- **배송지 폼 입력 규칙**:
  - 성함/연락처/배송지 주소 필수 입력. 미입력 시 `PAGE-07` 오류 모달 또는 인라인 Red Text 표시
- **1초 간편 결제**: 카카오페이 / 토스페이 / 신용카드 원터치 라디오 선택

## 5. 반응형 기준 및 접근성 표준
- **반응형 브레이크포인트**: Desktop Web (1920px FHD / Content Container 1200px~1440px), Tablet (768px ~ 1199px), Mobile (~767px)
- **접근성 요구사항**:
  - 이미지 대체 텍스트 (`alt="10초 원터치 부스터 앰플 섭취 이미지"`) 명시
  - 버튼 키보드 접근성 (Tab 키 포커스 Outline 표시)
  - 명도 대비 ratio 4.5:1 이상 준수 (네온 그린 #00FF66 vs 다크 그레이 #1A1A1A)

## 6. 가정 사항 (Assumptions)
- `가정 1`: 비회원 구독 시 결제 단계에서 1회성 휴대폰 본인인증으로 가입이 간편 자동 완료된다.
- `가정 2`: 결제 PG사는 카카오페이, 토스페이, 국내 전 신용카드를 지원한다.
