## 1. 서비스 전체 흐름 (User Journey Flow)

사용자가 A:FIT Glow 메인 웹사이트에 진입하여 **피부 속건조 문제 인식 ➔ AI 피부 큐레이션 진단 ➔ 성분 흡수율 검증 ➔ 정기구독 결제**에 도달하는 프로세스입니다.

```text
[1. 메인 접속]
   │
   ▼
[2. PAGE-01: Hero 속건조 공감 탐색]
   │
   ├───────► (예: AI 진단 클릭) ──► [3. PAGE-03: AI 피부 큐레이션 3단계 진단]
   │                                           │
   ▼ (아니오: 스크롤 탐색)                      ▼ (진단 완료)
[4. PAGE-04: 흡수율 비교표 & 성분 차트] ◄───────┘ (맞춤 바이오 앰플 팩 추천)
   │
   ▼
[5. Glow 정기구독 플랜 선택]
   │
   ▼
[6. PAGE-05: 최단 결제 동선 (배송지 입력 & 1초 결제)]
   │
   ├───────► (결제 승인 성공) ──► [7. PAGE-06: 구독 완료 & 배송 타임라인] (종료)
   │
   └───────► (결제 승인 실패) ──► [8. PAGE-07: 오류/예외 모달] ──► (다시 결제)
```

---

## 2. Mermaid 서비스 흐름도

```mermaid
flowchart TD
    Start([시작: 메인 접속]) --> Hero[PAGE-01: Hero 탐색]
    Hero --> Quiz{AI 피부 큐레이션 실행?}
    
    Quiz -- 예 --> Modal[PAGE-03: AI 큐레이션 모달]
    Quiz -- 아니오 --> Value[PAGE-04: 성분 & 흡수율 비교]
    
    Modal --> Recommendation[맞춤 바이오 앰플 팩 도출]
    Recommendation --> Value
    
    Value --> PlanSelect[Glow 구독 플랜 선택]
    PlanSelect --> Checkout[PAGE-05: 구독 결제 창]
    
    Checkout --> PaySuccess{결제 승인 성공?}
    PaySuccess -- 성공 --> Success[PAGE-06: 구독 완료]
    PaySuccess -- 실패 --> Error[PAGE-07: 오류/예외 모달]
    
    Error --> Checkout
    Success --> End([종료: 배송 안내])
```

## 3. 단계별 주요 전환 조건 및 예외 명세

1. **AI 피부 큐레이션 진단**:
   - 1단계(피부 고민: 속건조/미백/탄력/트러블), 2단계(클렌징 습관), 3단계(필요 바이오 성분) 칩 미선택 시 다음 버튼 비활성화.
2. **구독 결제 유효성 검사**:
   - 성함, 연락처, 배송지 미입력 시 인라인 에러 텍스트 표출 및 결제 승인 요청 차단.
3. **결제 오류 대응 (PAGE-07)**:
   - 한도 초과, 잔액 부족, 네트워크 오류 발생 시 즉각 PAGE-07 모달을 띄우고 "재결제" 및 "CS 채널톡 상담" 이동 버튼 제공.
