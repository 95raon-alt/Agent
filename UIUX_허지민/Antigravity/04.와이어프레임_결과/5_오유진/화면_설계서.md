## 3. 화면별 구성 영역, UI 요소 및 인터랙션 명세

### 3.1 [PAGE-01] 메인 랜딩페이지
- **진입 조건**: 웹 브라우저 URL 접속 또는 SNS 비건/친환경 광고 링크 클릭
- **종료 조건**: 구독 결제 버튼 클릭(PAGE-05 이동) 또는 AI 큐레이션 모달 열기(PAGE-03 이동)
- **주요 UI 영역 및 컴포넌트**:
  - `Header`: A:FIT Eco 로고, GNB (스토리, AI 큐레이션, 클린 성분, 구독 혜택), 장바구니 Icon
  - `Hero Section`: "지구에도, 내 몸에도 무해하게! 10초 만에 챙기는 100% 비건 이중제형" 카피, 내추럴 샌드 / 세이지 그린 클린 비주얼
  - `Problem & 3-Line Summary`: 용기 쓰레기 및 화학첨가물 공감 카피, `[플라스틱 ZERO - 100% 비건 - 10초 클린 앰플]` 3줄 요약 카드
  - `AI Eco Curation`: 4대 에코 라이프 칩 (비건 지향/제로웨이스트/클린/입문), AI 연동 맞춤 식물성 앰플 추천 모크업 UI
  - `Vegan ESG Donut Chart`: 100% 프랑스 비건 인증 및 탄소 발자국 절감 도넛 차트 (마우스 호버 시 탄소 절감 수치 인터랙션 연산)
  - `10s GIF Motion`: 생분해 보틀 뚜껑을 눌러 마시는 10초 원샷 이중제형 애니메이션/GIF
  - `Reviews`: 환경 운동가, 비건 셰프, 클린 웰니스 인플루언서 실명 후기 횡스크롤 슬라이더
  - `Sticky CTA Bar`: 화면 하단 스크롤 추종 구독 결제 바 ("지구와 내 몸을 위한 10초 클린 에코 구독 시작하기")
- **반응형 대응**:
  - PC Web (1920px FHD, Max-Width 1200px~1440px Container): 12컬럼 그리드, 도넛 차트와 큐레이션 모크업 좌우 병렬 배치
  - Mobile (~767px): 1컬럼 수직 스태킹, 횡스크롤 슬라이더 touch-swipe 활성화

### 3.2 [PAGE-03] AI 에코 큐레이션 모달
- **3단계 에코 퀴즈**: 1단계(라이프스타일), 2단계(식습관 습관), 3단계(필요 식물성 성분) 칩 선택
- **유효성 검사**: 각 단계별 최소 1개 이상 칩 미선택 시 "다음" 버튼 비활성화 (Disabled State)

### 3.3 [PAGE-05] 구독 결제 창
- **배송지 폼 및 회수 동의**:
  - 성함/연락처/배송지 주소 필수 입력. 생분해 용기 무료 회수 동의 체크박스 제공
- **1초 간편 결제**: 카카오페이 / 토스페이 / 신용카드 원터치 라디오 선택
