- **프로젝트명**: A:FIT (에이핏) 2030 초개인화 이중제형 올인원 건강식 정기구독 메인 웹사이트
- **클라이언트**: 박지안 ([B2C 실제 사용자] 2030 피로 누적 IT 직장인 페르소나)
- **설계 범위**: 메인 랜딩페이지(PAGE-01), 브랜드 스토리(PAGE-02), 맞춤 진단 모달(PAGE-03), 가성비 혜택(PAGE-04), 구독 결제 창(PAGE-05), 구독 완료(PAGE-06), 오류/예외 모달(PAGE-07), 404 안내(PAGE-08) 전체 화면

## 3. 화면별 구성 영역, UI 요소 및 인터랙션 명세

### 3.1 [PAGE-01] 메인 랜딩페이지
- **진입 조건**: 웹 브라우저 URL 접속 또는 외부 광고 링크 클릭
- **종료 조건**: 구독 결제 버튼 클릭(PAGE-05 이동) 또는 진단 모달 열기(PAGE-03 이동)
- **주요 UI 영역 및 컴포넌트**:
  - `Header`: A:FIT 로고, GNB (스토리, 진단, 혜택, 신청), 장바구니 Icon
  - `Hero Section`: "식사부터 영양제까지 10초 컷, 커피 한 잔 값으로 완성하는 바른 내일" 임팩트 카피, 보틀+캡슐 이중제형 오브제 비주얼
  - `Problem & 3-Line Summary`: 2030 시간/식비 부족 공감 카피, `[효능 - 식비 절감 - 섭취 편의]` 3줄 요약 카드
  - `Smart Curation`: 5대 고민 이모지 라디오 칩 (밤샘/회식/붓기/야식/피로), 1:1 맞춤 진단 모크업 & 알고리즘 자동 생성 메시지 라벨("어제 야근한 지안님을 위한~") 각인 3D 프리뷰 UI
  - `Cost Chart`: 편의점 도시락(6,500원) vs A:FIT(3,900원) 식비 절감 데이터 저울 UI (슬라이더 조절 시 기울기 애니메이션 연산)
  - `GIF Motion`: 물 없이 마시는 10초 원핸드 뚜껑 개봉 스크롤 애니메이션/GIF
  - `Reviews`: 18가지 페르소나(취준생, 3교대 간호사, 개발자 등) 실명 후기 횡스크롤 슬라이더
  - `Sticky CTA Bar`: 화면 하단 스크롤 추종 구독 결제 바 ("커피 한 잔 값으로 내 컨디션 맞춤 구독 시작하기")
- **반응형 대응**:
  - PC Web (1920px FHD, Max-Width 1200px~1440px Container): 12컬럼 그리드, 저울 차트와 진단 모크업 좌우 병렬 배치
  - Mobile (~767px): 1컬럼 수직 스태킹, 횡스크롤 슬라이더 touch-swipe 활성화

### 3.2 [PAGE-03] 맞춤 진단 모달
- **진단 퀴즈**: 1단계(현재 컨디션), 2단계(식습관/야식 빈도), 3단계(필요 효능) 칩 선택
- **유효성 검사**: 각 단계별 최소 1개 이상 칩 미선택 시 "다음" 버튼 비활성화 (Disabled State)

### 3.3 [PAGE-05] 구독 결제 창
- **배송지 폼 입력 규칙**:
  - 성함/연락처/배송지 주소 필수 입력. 연락처 미입력 시 `PAGE-07` 오류 모달 또는 인라인 Red Text 표시
- **1초 간편 결제**: 카카오페이 / 토스페이 / 신용카드 원터치 라디오 선택

## 5. 반응형 기준 및 접근성 표준
- **반응형 브레이크포인트**: Desktop Web (1920px FHD / Content Container 1200px~1440px), Tablet (768px ~ 1199px), Mobile (~767px)
- **접근성 요구사항**:
  - 이미지 대체 텍스트 (`alt="10초 컷 이중제형 보틀 이미지"`) 100% 명시
  - 버튼 키보드 접근성 (Tab 키 포커스 Outline 표시)
  - 명도 대비 ratio 4.5:1 이상 준수 (딥 그린 #183D33 vs 크림 화이트 #FAF6EB)

## 6. 가정 사항 (Assumptions)
- `가정 1`: 비회원 구독 시 결제 단계에서 1회성 휴대폰 본인인증으로 가입이 간편 자동 완료된다.
- `가정 2`: 결제 PG사는 카카오페이, 토스페이, 국내 전 신용카드를 기본 지원한다.
