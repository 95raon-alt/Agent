## 클라이언트. 박지안 ([B2C 실제 사용자] 2030 피로 누적 IT 직장인 페르소나)

## 1. 가상 클라이언트의 기본 정보 설정

- **클라이언트 이름 및 직책**: 박지안 ([B2C 실제 사용자] 2030 피로 누적 IT 직장인 페르소나)
- **프로젝트의 중심 주제**: A:FIT (2030 직장인/1인가구 타깃 상황 맞춤형 이중제형 올인원 건강식 정기구독 서비스)
- **제작 목적 (클라이언트 방문/구매 목적)**: [본인 직접 섭취 유즈케이스] 시간과 식비가 부족한 2030 피로 누적 직장인이 본인의 영양/식사 해결과 가성비를 위해 1:1 맞춤 건강 진단을 받고, 알고리즘이 자동 생성한 본인 맞춤 라벨 메시지(예: "어제 밤샘 야근한 지안님을 위한 붓기 타파 팩") 각인 3D 프리뷰를 확인한 후 10초 D2C 맞춤 정기구독을 진행하는 본인 구매 웹사이트 구축
- **클라이언트가 제공한 자료**: 박지안 디렉터 1차 클라이언트 브리프, 18가지 페르소나 심층 인터뷰 데이터, 사용자 음성 녹음 STT 분석 보고서
- **필요한 정보와 기능**:
  - 타깃 상황별(회식, 밤샘, 붓기 등) 맞춤 캡슐 추천 이모지 칩/라디오 버튼 UI
  - 편의점 도시락/커피 대비 절약 금액을 시각화하는 가성비 저울/데이터 차트 UI
  - 물 없이 10초 만에 마시는 원핸드 이중제형(보틀+뚜껑 캡슐) 액션 모션 GIF
  - 1:1 개인 건강상태 맞춤 진단 분석 모크업 & 진단 알고리즘 자동 생성 메시지 라벨("어제 밤샘 야근한 지안님을 위한~") 각인 3D 프리뷰 UI
  - 타깃 공감형 3줄 요약 카드 및 횡스크롤 리뷰 슬라이더
  - 하단 고정(Sticky Bar) 10초 맞춤 구독 결제 CTA
- **중요도와 작업 우선순위**:
  1. 극단적 가성비(식비 절감) 및 시간 효율 데이터 시각화 (우선순위: 높음)
  2. 스마트폰 앱 연동 진단 모크업 경험 (우선순위: 높음)
  3. 10초 컷 원핸드 이중제형 섭취 그래픽 (우선순위: 보통)
  4. 2030 페르소나 공감 리뷰 (우선순위: 보통)
- **적용 매체**: 데스크톱/PC 중심 대화형 반응형 웹 (Desktop-Centric Responsive Web)

```text
A:FIT 메인 웹사이트

├─ 3. Smart Curation (앱 연동 진단 모크업)
│  ├─ 상황별 큐레이션 이모지 칩 (밤샘/회식/붓기/피로)

├─ 4. Cost Efficiency Data (가성비 저울 UI)

│  └─ 3줄 요약 영양/성분 데이터표
├─ 5. Dual-Formulation Tech (오브제 패키지)
│  └─ 10초 컷 원핸드 섭취 액션 GIF
├─ 6. Target Persona Reviews (공감 리뷰)
│  ├─ 취준생/간호사/개발자 후기 슬라이더
│  └─ FAQ 아코디언
└─ 7. Footer & Sticky CTA
   ├─ 하단 고정 구독 결제 바 (Sticky Bar)
   └─ 푸터 (기업정보, 저작권, 약관)
```

## 9. 최종 작성 양식 (가상클라이언트 기반 결과 보고서)

### 1. 가상 클라이언트
- **프로젝트 주제**: A:FIT (2030 직장인/1인가구 타깃 상황 맞춤형 이중제형 올인원 건강식 정기구독 서비스)
- **제작 목적 (방문/구매 목적)**: [본인 직접 섭취 유즈케이스] 시간과 식비가 부족한 2030 본인 사용자가 직접 1:1 맞춤 건강 진단을 받고, 알고리즘 자동 생성 케어 메시지 라벨 각인을 확인하여 본인 전용 정기구독 신청 및 관리
- **제공 자료**: 박지안 디렉터 1차 클라이언트 브리프, 18가지 페르소나 심층 인터뷰, 음성 STT 보고서
- **적용 매체**: 데스크톱/PC 중심 대화형 반응형 웹 (Desktop-Centric Responsive Web)

### 2. 클라이언트 요구사항
- **요청 항목**: 시간/식비 공감 카피, 앱 연동 진단 모크업, 상황별 이모지 칩, 식비 비교 데이터 차트, 10초 컷 섭취 GIF, 오브제 패키지, 페르소나 리뷰, 하단 CTA
- **중요도**: 식비 절감 데이터 시각화(높음), 앱 연동 진단 모크업(높음), 하단 Sticky CTA(높음), 10초 컷 GIF(보통), 리뷰(보통)
- **관련 자료**: 편의점 식비 비교 데이터셋, 이중제형 용기 3D 모델
- **필요한 기능**: 라디오 칩 선택 UX, 데이터 저울 차트 모션, 10초 GIF 재생, 후기 횡스크롤 슬라이더, 하단 고정 결제 바
