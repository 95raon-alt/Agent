# 🤖 A:FIT 로고 레퍼런스 자동화 에이전트 실행 수칙 (로고/AGENTS.md)

## 1. 개요
본 문서는 사용자 명령어(`"실행 시작"`)에 반응하여 핀터레스트 레퍼런스 수집 파이프라인(`pin.md`)과 레퍼런스 분석 및 Flow 프롬프트 생성 파이프라인(`pin분석.md`)을 순차적으로 자동 실행하기 위한 에이전트 동작 수칙입니다.

## 2. 트리거 명령어 및 실행 수량 규정
- **기본 명령어**: `"실행 시작"` (기본 실행 수량: 1회)
- **수량 지정 명령어**: `"실행 시작 [N]가지"` 또는 `"실행 시작 [N]개"`
  - *예시*: `"실행 시작 3가지"` → 레퍼런스 3개 수집 및 3개 분석/프롬프트 도출
  - 숫자가 지정되면 입력된 숫자 N만큼 수집 및 분석을 연쇄 실행합니다.

## 3. 연쇄 실행 파이프라인 (Execution Pipeline)

### [단계 1] 레퍼런스 수집 (`로고/pin.md` 기반)
1. `로고/input/` 및 `로고/레퍼런스/` 폴더를 참조하여 조건에 부합하는 레퍼런스를 핀터레스트에서 탐색합니다.
2. 지정된 N개 수량만큼 이미지 검증(2D 플랫 벡터, 순수 흰색 배경, 검정 단색 워드마크)을 수행합니다.
3. 캡처된 이미지를 `로고/output/` 폴더에 `.jpg` 형식으로 저장을 완료합니다.

### [단계 2] 레퍼런스 분석 및 Flow 프롬프트 생성 (`로고/pin분석.md` 기반)
1. `로고/output/` 폴더에 이미지 저장이 완료되는 즉시 자동으로 `pin분석.md`를 실행합니다.
2. 새로 저장된 N개의 이미지를 개별 분석하여 100% 영문(English) Flow 이미지 생성 프롬프트를 도출합니다.
3. 작성된 프롬프트를 `로고/output/flow.md` 파일에 이미지 파일명을 대제목(`#`)으로 명시하여 기록합니다.

## 4. 중복 실행 제어 수칙
- 이미 분석 및 생성이 완료된 이미지는 사용자가 **"재실행"** 명령을 입력하기 전까지 재작성하거나 재처리하지 않습니다.
