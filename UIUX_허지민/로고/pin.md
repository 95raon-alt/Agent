# 📌 A:FIT 핀터레스트 로고 레퍼런스 수집 가이드라인 (pin.md)

## 1. 실행 명령
사용자가 **`"레퍼런스 수집 시작해"`** 또는 **`"실행 시작 [N]개"`**라고 명령하면 이 문서의 절차를 즉시 실행한다. 필요한 폴더와 이미지가 존재하면 추가 질문 없이 연쇄 파이프라인을 진행한다.

## 2. 입력과 출력
- **형태 기준**: `로고/input/` 폴더의 손그림 초안 이미지 (`로고_초안_0.jpg` ~ `로고_초안_5.jpg`)
- **스타일 기준**: `로고/레퍼런스/` 폴더의 참고 이미지
- **결과 저장**: `로고/output/`
- **기본 수집 개수**: 사용자가 N을 지정하지 않으면 기본 1개 수집 (N 지정 시 N개 연쇄 실행)
- **파일 형식**: 실제 JPEG (`.jpg`)
- **파일명 규칙**: `유사_로고_1.jpg`, `유사_로고_2.jpg`처럼 사용되지 않은 다음 연번 지정
- **중복 제어**: 기존 수집/분석 결과물은 명시적인 "재실행" 요청 없이 덮어쓰지 않는다.

## 3. 분석 기준
검색 전 `로고/input/`과 `로고/레퍼런스/` 폴더 내 지원 이미지(JPG, JPEG, PNG, WebP)를 모두 실제 확인한다.

### 3.1 input 분석
1. 기본 도형 요소 및 개수 (원형, 삼각, 이중제형, 모노그램 등)
2. 대칭형, 곡선 결합, 이중 루프, 듀얼 레이어 등의 배치 구조
3. 선 굵기, 단선/면 구성, 끝 처리, 핸드 드로잉 스케치 특징
4. 미니멀, 유기적, 현대적, 신뢰감 등의 전체 비주얼 인상
5. 반드시 유지할 형태적 시각 특징 2~3개 추출

### 3.2 레퍼런스 분석
1. 색상과 명도 (순수 흰색 배경 `#FFFFFF`, 단색 검정 `#000000`)
2. 선과 면의 2D 플랫 그래픽 표현 방식
3. 여백과 정렬 밸런스
4. 심볼 및 모노그램이 제시되는 방식
5. 결과물로 선호하는 하이엔드 웰니스 시각적 완성도

*형태와 조형 구조는 `input`을 우선하고, 표현 방식은 `레퍼런스` 및 브랜드 제약 조건을 우선한다.*

## 4. 브랜드 방향 (A:FIT 전용)
- **로고 텍스트**: A:FIT
- **브랜드 컨셉**: 2030 식비·시간을 아끼는 1:1 맞춤 영양 & 라벨 각인 이중제형 구독
- **비주얼 톤앤매너**: 미니멀, 모던, 세련됨, 신뢰감, 클린
- **디자인 제약 조건**:
  - 배경색: 순수 흰색 (`#FFFFFF` / Clean White)
  - 로고색: 단색 검정 (`#000000` / Monochrome Black)
  - 제형: 2D 플랫 벡터 (Flat Vector Graphics)
  - 단일 로고 원칙: 작도선/그리드가 전혀 없는 순수 단일 로고 심볼(Clean Standalone Logo)만 수집 및 프롬프트화

## 5. Pinterest 검색어 작성
검색어는 `[핵심 형태] + [구성 방식] + [스타일] + logo mark` 구조의 영어 문구로 조합하며, 서로 다른 검색어를 최소 3개 이상 활용한다.

### A:FIT 권장 검색어 (4가지 다변화 컨셉):
1. **웰니스 워드마크 & 액체 모노그램**:
   - `modern wellness beverage wordmark logo black white`
   - `clean health drink typography logo`
   - `fluid organic monogram logo flat vector`
   - `minimalist liquid supplement logo`
2. **볼드 기하학 & 럭셔리 타이포그래피**:
   - `bold geometric logo design flat vector`
   - `minimalist angular logo black white`
   - `luxury minimalist supplement logo design`
   - `high-end clean brand identity vector`
3. **이중제형 & 1:1 맞춤 피팅 심볼**:
   - `dual formula supplement logo design vector`
   - `personalized custom nutrition brand symbol black white`
   - `minimalist infinity loop wellness logo`

## 6. 검색과 선정 절차
1. 서로 다른 영어 검색어를 최소 3개 실행한다.
2. 개별 Pinterest 핀 URL(`/pin/…`) 또는 부합하는 2D 플랫 벡터를 후보로 수집한다.
3. 형태, 배치와 흐름, 선 스타일, A:FIT 브랜드 분위기를 각각 비교한다.
4. 검증 체크리스트 항목 중 세 항목 이상이 부합하는 고품질 이미지/심볼만 최종 채택한다.
5. 요청된 개수 N만큼 `로고/output/` 폴더에 최종 저장한다.

## 7. 제외 조건 (Strict Exclusions)
- **그리드/작도선 포함 금지**: 모눈종이, 가이드라인, 원형 그리드, 휠선이 포함된 이미지 제외
- **컬러 적용 금지**: 무채색(검정/흰색) 외 모든 색상이 포함된 디자인 제외
- **목업(Mockup) 표현 금지**: 3D 용기/입체 목업, 질감 배경, 종이/명함/패브릭 질감 합성 디자인 제외
- **UI 요소 포함 금지**: Pinterest 메뉴, 버튼, 돋보기/화살표, 검색창 등 UI가 포함된 캡처 제외
- **독립 마스코트/사진 금지**: 사진, 3D 렌더링, 과도한 그라데이션, 브랜드와 무관한 마스코트 제외

## 8. 캡처와 저장
1. 로고 이미지가 순수 흰색 배경에 크고 또렷하게 보이는지 확인한다.
2. UI 요소나 팝업 없이 순수 2D 로고 심볼 영역만 정밀 캡처/저장한다.
3. PNG나 WebP 형식은 포맷 변환을 거쳐 실제 JPEG (`.jpg`) 형식으로 저장한다.
4. 저장한 JPG를 육안 검증하여 그리드, UI 아이콘, 목업, 워터마크 여부를 최종 확인한다.

## 9. 연쇄 파이프라인 자동 실행 (`pin분석.md`)
- `로고/output/` 폴더에 N개 이미지 저장이 완료되는 즉시 자동으로 `pin분석.md`를 실행한다.
- 수집된 신규 이미지별로 100% 영문 Flow 생성 프롬프트(부정 프롬프트 포함)를 작성하여 `로고/output/flow.md`에 기록을 완료한다.

## 10. 완료 보고
- 저장 파일 경로 (예: `로고/output/유사_로고_N.jpg`)
- 초안 및 A:FIT 브랜드 컨셉과 유사/부합하는 핵심 이유 1~2문장
- `로고/output/flow.md` 파일에 영문 프롬프트 기록 반영 여부 보고
